# Strong 8k

Marketing site for Strong 8k IPTV (`https://8k-strong.us`).

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (static export)
- TypeScript
- Tailwind CSS
- Framer Motion
